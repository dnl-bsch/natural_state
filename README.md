# Natural State take-home project

> **Use of AI.** All code in this repository was generated by an AI assistant (Claude, through Claude Code).
> I checked it: I reviewed the code, ran it, and compared its results with the data and the SOPs. The reports and
> this README were also drafted with AI and reviewed by me. The analytical decisions and their justification are
> mine to explain and defend.

This repository solves two challenges:

- **Vegetation:** clean, join and QA/QC the herbaceous vegetation survey data, then write a data quality report
  and a handover for the Tech team.
- **Birds:** turn BirdNET predictions into bird observations with a 99 % probability-of-correctness cutoff,
  following Wood & Kahl (2024).

## Installation

The project uses [uv](https://docs.astral.sh/uv/) and Python 3.13.

```bash
# Install uv, if needed (macOS and Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create the virtual environment and install all dependencies, including the development tools
uv sync
```

The data are not part of the repository. Place the raw files like this:

```text
data/raw/birds/birdnet_predictions.csv
data/raw/birds/validation_results.csv
data/raw/vegetation/ODK Data Exports/...
data/raw/vegetation/Entity lists/...
```

## Vegetation

The analysis is the notebook `notebooks/vegetation.ipynb`. Open it in Jupyter or VS Code with the
`natural-state` kernel and run all cells, or run the paired script from the repository root:

```bash
MPLBACKEND=Agg uv run python notebooks/vegetation.py
```

The GBIF name check calls the GBIF web service, so this step needs an internet connection.

The notebook writes its tables and figures to `data/output/vegetation/`:

| File | Content |
|---|---|
| `flags.csv`, `flag_overview.csv` | Every flagged data problem, and counts per check |
| `survey_summary.csv`, `plot_summary.csv` | Survey-level and plot-level summaries |
| `species_records.csv` | One row per species per quadrat |
| `sampling_design.csv` | Planned, registered and surveyed plots per stratum |
| `figures/` | Species accumulation curves and the transect map |

The two deliverables are written by hand from these outputs, in the same folder:

- `vegetation_data_quality_report.md`, the data quality report
- `vegetation_tech_handover.md`, the specification for the Tech team

## Birds

The code is the package `src/natural_state/birds/`. Run the whole pipeline with:

```bash
uv run birds                    # reads data/raw/birds, writes data/output/birds
uv run birds --p-target 0.95    # use a different required probability
uv run birds --help             # all options
```

The pipeline writes to `data/output/birds/`:

| File | Content |
|---|---|
| `birdnet_predictions_with_observation.csv` | Every prediction, with `p_correct`, `threshold_status` and `observation` |
| `species_thresholds.csv` | The threshold decision per species, with the fitted model |
| `observation_summary.csv` | Predictions, observations and share accepted per species |
| `figures/bird_calibration_curves.png` | Validated clips and fitted curve per species |

The notebook `notebooks/birds.ipynb` walks through the same steps and explains the decisions.

| Module | What it does |
|---|---|
| `settings.py` | Parameters, such as the target probability and the minimum number of validated clips |
| `data.py` | Loads the predictions and validations, and checks columns and value ranges |
| `regression.py` | Logit conversion, logistic regression, threshold and bootstrap interval |
| `thresholds.py` | Decides a threshold per species: `logistic_fit`, `score_independent` or `insufficient_validation` |
| `observations.py` | Labels each prediction as an observation or not, and summarises per species |
| `plots.py` | Figure of the fitted curves per species |
| `pipeline.py` | Runs all steps and writes the outputs |

## Development

### Notebooks and jupytext

Each notebook is paired with a plain Python script in the "percent" format, for example
`notebooks/birds.ipynb` and `notebooks/birds.py`. The script gives readable diffs in git.

```bash
# After editing either file, bring the other one up to date
uv run jupytext --sync notebooks/birds.ipynb notebooks/vegetation.ipynb

# Pair a new notebook with a script
uv run jupytext --set-formats ipynb,py:percent notebooks/new_notebook.ipynb
```

VS Code and Jupyter do not sync automatically, so run `--sync` before committing.

### Tests

The unit tests cover the bird package, in particular the regression and the threshold rules.

```bash
uv run pytest           # all tests
uv run pytest -v        # one line per test
uv run pytest tests/test_regression.py
```

### Type checking with mypy

mypy runs in strict mode on `src/` and `tests/`.

```bash
uv run mypy
```

### Linting and formatting with ruff

ruff checks style, imports, common bugs and NumPy-style docstrings in `src/`. The notebooks are excluded
because they are exploratory.

```bash
uv run ruff check           # lint
uv run ruff check --fix     # lint and fix what can be fixed automatically
uv run ruff format          # format
```
